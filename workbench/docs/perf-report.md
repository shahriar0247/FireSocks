# FireSocks performance report

## Methodology

- Immutable control: `workbench/controls/FireSocks-control-thinlto.app`
  (opt + ThinLTO, arm64, from packaged `firesocks-162.0a1.en-US.mac.dmg`).
- Treatment: `obj-opt/dist/FireSocks.app` after the PGO three-stage build.
- Paired A/B: `workbench/bench/ab.sh` runs counterbalanced ABBA blocks,
  `report.py` computes per-block diffs with a bootstrap 95% interval and
  refuses incomplete blocks (exit 2).
- Provenance per run: binary sha256, git HEAD, mozconfig hash, clang version,
  macOS version, chip, thermal state (CPU_Speed_Limit), loadavg, power source,
  low-power mode. Raw browsertime JSON + provenance in `workbench/bench/results/`.
- Scores unprofiled. Profiled runs used only for attribution.
